# Quark 
Quark is a fork of one of the most text editors - Atom. Since GitHub team has stopped development, I wanna make a simple text editor, which could work on any OS: macOS, Arch Linux, Fedora Linux, Gentoo Linux, etc.

Main purpose is to make a simple text editor, add some Vim shortcuts in it and make it look a little bit more fresh. 

And don't forget: it is just an Atom fork! Now it is gone... Press F! I took this name just because quark is smaller than atom so it could be the best idea for light-weight Atom fork.
